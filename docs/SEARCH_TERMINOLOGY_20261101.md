# Search terminology evidence — 1 November 2026

Scope: English seed terminology for existing draft metadata. This is a qualitative vocabulary check, not search-volume, ranking, conversion or trademark evidence. Other markets still require local reviewers.

| Intent | Draft phrase | Primary-source basis | FloraTend support |
| --- | --- | --- | --- |
| Remember routine care | plant watering reminder | [Planta custom care](https://getplanta.com/discover/iam/custom/care) describes configurable reminders; [Greg support](https://greg.app/support/) describes watering recommendations and upcoming care. | User schedules and local reminders; check conditions before watering. |
| Plan repeated tasks | plant care schedule | The same official product help uses care routines, tasks and schedules. | Soil checks, fertilising, pruning, repotting and custom recurrence. |
| Organise indoor plants | houseplant tracker | [RHS houseplants](https://www.rhs.org.uk/plants/types/houseplants) uses houseplants, indoor plants and individual rooms. “Tracker” is an inferred product-intent term, not a quoted RHS term or measured query. | Names, species, categories, locations, search and filters. |
| Keep observations | plant growth journal | “Growth journal” is an inferred description of the implemented dated observations; it is not validated by this search as a high-volume query. | Dated notes, private photos, height and leaf counts. |
| Broad category | plant care | Both official product help and RHS use this category language. | Organisation and observation; no diagnosis or automatic watering decision. |

The five existing English keyword phrases map to distinct implemented tasks. They contain no competitor brand names or repeated comma-separated variants. This limited set is a defensible draft, not proof that it maximises discovery. Competitor algorithms, identification, health diagnosis and automatic environmental recommendations must not be implied as FloraTend capabilities.

[RHS growing guidance](https://www.rhs.org.uk/plants/types/houseplants/growing-guide) explains that watering needs change with conditions. This supports the existing “inspect first” product wording; a calendar reminder cannot guarantee that water is needed. No competitor reviews, install counts or endorsements are reused.

Current listing drafts and screenshot headlines remain pending human linguistic/claims approval. No public listing was changed by this research.
